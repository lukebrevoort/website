Start with the cheap checks.

These checks find contract, TypeScript, and production-build failures before a real model request costs time or money.

Configure the server-only key

Copy the names from .env.example into a gitignored .env.local. The key must never use a NEXT_PUBLIC_ prefix.

OPENAI_API_KEY=your_openai_project_key
CANVAS_VISION_PROVIDER=openai
CANVAS_OPENAI_MODEL=gpt-5.4

Run the automated release gate

All three commands should exit successfully. The build is the production TypeScript check.

npm test
npx tsc --noEmit
npm run build

Open the actual Explore surface

Start the app, open the URL below, and keep DevTools Console and Network visible for the first real request.

npm run dev
# open http://localhost:3000/explore

Probe the API boundary without calling OpenAI

The first request should return 415; the second should return 400. Both are rejected before provider invocation.

curl -i -X POST http://localhost:3000/api/canvas-agent \
  -H 'content-type: text/plain' \
  --data '{}'

curl -i -X POST http://localhost:3000/api/canvas-agent \
  -H 'content-type: application/json' \
  --data '{}'
Known local-only warning: a production-mode localhost run may return 404 for /_vercel/speed-insights/script.js. Vercel supplies that script when hosted; do not treat that isolated warning as a canvas-agent failure.

Judge the result, not just the response.

A 200 only proves the wire works. Use a small prompt suite to judge factual grounding, composition, continuity, and responsive layout.

Baseline architecture

“Sketch how MALCOM works”

Expect a clear title, a readable flow, labeled relationships, and a takeaway—not a pile of generic boxes.

Cross-project grounding

“Compare MALCOM and Dispatch”

Expect project-specific details from both entries. Treat invented databases, users, metrics, or capabilities as a failure.

Conversation continuity

“Where does human approval happen?”

Ask this after a FlowState sketch. The addition should build on the existing board instead of restarting the answer.

Mobile composition

390 × 844 · fresh load · starter prompt

Expect a readable vertical stack with sensible spacing. Reject a tiny, compressed desktop diagram.

Visual bar: text stays short and readable; boxes do not heavily overlap; connectors avoid unrelated nodes; one restrained accent supports hierarchy; all returned elements remain individually editable in Excalidraw.

Try to make it fail safely.

The board is the valuable state. Every recovery path should leave it unchanged unless the visitor explicitly accepts a valid patch.

Wire the hosted environment.

The browser sends requests to your same-origin Next.js route. OpenAI credentials live only in the Vercel function environment; the firewall sits in front of that route at Vercel’s edge.

Add environment variables in Vercel

Project → Settings → Environment Variables. Add OPENAI_API_KEY to Preview and Production. Optionally add the provider and model overrides shown above.

Redeploy after an environment change

Environment edits only affect new deployments. Redeploy the exact branch/commit you plan to test.

Test the hosted /explore

Confirm one real prompt succeeds on the Preview URL. If Deployment Protection is enabled, authenticate normally before diagnosing the agent route.

Do not add a browser API secret. This is a public visitor experience. A custom secret header in client code would be visible to every visitor; use the server-only OpenAI key plus Vercel’s edge firewall instead.

Protect the expensive route.

You need a Vercel Project Admin, Team Member, or Security role. Localhost cannot exercise Vercel Firewall; publish the rule and test against the Vercel-hosted domain.

Create the match as Log first

Project → Firewall → Configure → Add New… → Rule. Add the path and method conditions with AND, choose Log, then Save → Review Changes → Publish.

Prove the match

Send one normal prompt. In Firewall → Overview/Traffic, use the live 10-minute view and filter by the rule or /api/canvas-agent. Confirm only the intended POST is matched.

Change the action to rate limiting

Edit the rule to the values above and publish again. Choose the action that returns 429, not a permanent block. The client already has a friendly 429 recovery message.

Verify it without invoking the model

Run this against the published domain. The invalid bodies should produce five application-level 400s, then one edge-level 429.

DEPLOYMENT_URL='https://your-domain.example'

for request_number in 1 2 3 4 5 6; do
  curl -sS -o /dev/null \
    -w "$request_number -> %{http_code}\n" \
    -X POST "$DEPLOYMENT_URL/api/canvas-agent" \
    -H 'content-type: application/json' \
    --data '{}'
done

# Expected:
# 1–5 -> 400
# 6   -> 429

Confirm the edge event

Return to Firewall traffic and filter by the rule. Confirm the rate-limited request appears, then wait for the 10-minute window before the final real-prompt check.

Shared-IP tradeoff: an office, school, or VPN can place many visitors behind one IP. Start at 5/10 minutes while traffic is small; if legitimate follow-ups are being blocked, raise the limit to 10 before changing the route scope or removing the guardrail.
If the Firewall Configure button is missing
Check your role on the Vercel team/project. The supported roles for configuring and applying WAF rules are Project Admin, Team Member, and Security. Ask the team owner to adjust your role; do not work around this by exposing a secret in the browser.
