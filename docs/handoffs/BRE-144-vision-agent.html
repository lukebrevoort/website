BRE-144 · Vision Agent

Scoped canvas context,
validated end to end.

The live Explore canvas now sends one bounded structural snapshot and its matching PNG to a server-only Gemini adapter after an explicit visitor submission.

1 · CaptureSelection, otherwise the visible viewport.
2 · BoundElements, PNG size, prompt, history, and request bytes.
3 · GenerateGemini returns a typed CanvasPatchV1.
4 · ValidateServer and client both run semantic validation.
5 · ApplyOne undoable transaction; risky changes pause for approval.

Server configuration

Set GOOGLE_GENERATIVE_AI_API_KEY in local and Vercel Preview environments. Optional overrides are CANVAS_VISION_PROVIDER=gemini and CANVAS_GEMINI_MODEL=gemini-2.5-flash. No provider value is serialized into the browser bundle or response.

When the credential, provider, or free-tier quota is unavailable, the API fails closed with a human-readable resting state. The board remains unchanged.

Manual preview checklist

  1. Open /explore, submit a starter prompt, and confirm native editable Excalidraw objects appear.
  2. Draw two marks, select one, submit a prompt, and confirm the response is scoped to the selection.
  3. Submit without a selection and confirm the visible viewport is used.
  4. Edit the board while a request is running; confirm the stale response is rejected without mutation.
  5. Trigger a large or destructive patch; confirm the board does not change before approval.
  6. Remove the preview credential and confirm the resting message appears while the mark count stays unchanged.
  7. Use Excalidraw Undo after an accepted patch and confirm the entire patch reverses as one action.
