Exact step-by-step wiring

Keep the feature branch based on homepage-canvas

The current branch is two commits ahead of origin/homepage-canvas. Transfer it through a focused PR whose base is homepage-canvas, not main.

git push origin agt_0ad3cc385281/scoped-canvas-context-model
# Create a draft PR:
# base: homepage-canvas
# head: agt_0ad3cc385281/scoped-canvas-context-model

Install the locked dependencies

The provider uses Vercel AI SDK 6, the Google adapter, and Zod 4 structured output. Use the committed lockfile.

npm ci

Configure the server-only OpenAI credential

Put the key in the gitignored local .env and in Vercel Project Settings for Preview and Production. The existing OpenAIKey name is accepted as a compatibility alias. Never prefix either name with NEXT_PUBLIC_.

OPENAI_API_KEY=your_openai_project_key
CANVAS_VISION_PROVIDER=openai
CANVAS_OPENAI_MODEL=gpt-4o-mini

Only the first variable is required. The provider and model variables are explicit, optional overrides.

Capture one bounded scene

captureAgentContext() checks Excalidraw selection state. A non-empty selection becomes the scope; otherwise the visible viewport does. The same bounds produce both the semantic element list and its PNG.

  • Maximum 40 semantic elements.
  • Maximum PNG edge 768 px; OpenAI receives it at low detail.
  • Maximum PNG payload 1.5 MB.
  • Coordinates normalized to integers from 0 through 1000.

Submit the matching request

homepage-whiteboard.tsx posts only after an explicit visitor action. Keep all five fields together; do not capture the image and structure at different moments.

{
  prompt,
  scope: "selection" | "viewport",
  context: { sceneVersion, bounds, elements },
  imageDataUrl: "data:image/png;base64,...",
  priorTurns: [{ prompt, summary }]
}

Validate before calling OpenAI

The route enforces the 1.9 MB HTTP budget, parses with canvasAgentRequestSchema, and fails closed if configuration is absent. Keep this in the server route; do not move provider calls into the browser.

Require semantic CanvasPatchV1 output

The OpenAI adapter receives at most four knowledge snippets, two prior-turn summaries, 40 elements, and one low-detail PNG. Output is capped at 1,400 tokens with no retries or response storage. It must return contract operations—never raw Excalidraw objects.

Enable the distributed per-IP limit in Vercel

Open the project’s Firewall → Configure → Custom Rules screen and create one rule with these exact values. This runs before the function and prevents rejected requests from spending OpenAI tokens.

Name: Canvas Q&A — 5 requests per IP per 10 minutes
Conditions: path equals /api/canvas-agent
            AND method equals POST
Action: rate_limit
Algorithm: fixed_window
Window: 600 seconds
Limit: 5
Key: ip
When exceeded: deny

Vercel returns HTTP 429 and rate-limit headers. The client converts that response into a wait-and-retry message.

Validate on both sides of the network

The server validates before responding. The client validates again before compilation. This catches invalid references, duplicate aliases, excessive text, out-of-bounds geometry, and unsupported fields.

Reject stale work and pause risky work

Before applying, compare the current scene version with the captured version. If the board changed, discard the response. Deletes, changes to visitor-authored marks, large moves, large created area, or unusually large patches must stop at the approval UI.

Compile and apply exactly once

compileCanvasPatch() resolves semantic refs into deterministic IDs and scene coordinates. applyCompiledPatch() converts created skeletons, applies all mutations, and calls updateScene once with CaptureUpdateAction.IMMEDIATELY, making the accepted patch one Undo action.

Promote only after preview verification

Run the automated checks, exercise the real OpenAI path and the fourth-request 429 path on desktop and mobile, inspect the screenshots, and wait for the exact Vercel Preview commit to pass. Merge the ticket PR into homepage-canvas.

Critical invariant: the provider proposes a semantic patch; it never mutates Excalidraw. Validation, risk approval, compilation, and the single scene transaction remain outside the model adapter.

Transfer checklist

  9. Exercise the approval and cancel paths.
  10. Verify one Undo removes one accepted patch.
  11. Test offline and missing-credential recovery.
